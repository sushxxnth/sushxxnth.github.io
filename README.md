# Sushanth Chandrashekar — Minimal academic website

A clean, one-page, mobile-friendly personal academic website, inspired by the understated profile-sidebar layout at https://bohanyao-nlp.github.io/.

## View and edit

Open `index.html` in your browser. This site uses only HTML and CSS, with no dependencies, JavaScript, cards, gradients, or animation.

- Edit biographical text, experience, publications and projects in `index.html`.
- Edit layout and typography in `styles.css`.
- Replace the GitHub profile image by placing your own portrait at `assets/profile.jpg` and changing the `<img class="avatar">` source in `index.html` to `assets/profile.jpg`.
- Update your CV by replacing `assets/Sushanth_CV.pdf`.

## Publish on GitHub Pages

1. Create the public repository `sushxxnth.github.io` under the account `sushxxnth`.
2. Upload the **contents** of this directory to the root of the repository.
3. Under **Settings → Pages**, select `Deploy from a branch`, then `main` and `/ (root)`.
4. Your site will appear at https://sushxxnth.github.io/ after GitHub Pages publishes it.

## Content notes

Education, research, industry experience, manuscripts and projects are based on the supplied CV. Manuscripts remain labeled "under review" and are not presented as published papers. GitHub and LinkedIn links came from that CV. The profile image is retrieved from GitHub at runtime; there is an offline fallback icon.
